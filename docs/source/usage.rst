Usage
=====

.. _installation:

Installation
------------

To use **mrshudson**, first install it using pip:

.. code-block:: console

   (.venv) $ pip install mrshudson

Guides
------

Start by choosing a project root, then build paths and filenames from your
experiment parameters. Python 3.10 or newer is required.
